Neural-state segmentation and reusable computation. (A) GSBS constructs state templates, searches candidate boundaries and selects the state count using t-distance. (B) Temporal prefixes supply reusable interval scores, $Q_{a,b}=F(a,b)$; single and double splits replace only their parent contribution. The best proposals undergo t-distance comparison and sequential refinement. (C) Two-dimensional prefixes of valid-pair counts, correlations and squared correlations provide within-state and adjacent-state statistics by four-corner queries. The full symmetric correlation matrix is shown; statistics use each eligible pair once. Three numerical backends feed a shared search controller. Data-derived elements use a 120-TR Sherlock fMRI excerpt~\cite{baldassano2020sherlock,chen2017shared}; heatmaps show feature subsets, while fitting uses all 4,230 voxels. Detailed construction and provenance are in Supplementary Section S4.

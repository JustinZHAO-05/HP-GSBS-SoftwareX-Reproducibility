## Future automatic archives

Keep this repository enabled in Zenodo's GitHub settings. Before a future release, update `.zenodo.json` and `CITATION.cff` to the new version and tag identity, then regenerate `SHA256SUMS.txt`. Publish the GitHub release and verify the resulting Zenodo record. `.zenodo.json` deliberately does not hard-code the current version DOI, so future automatic archives can receive their own version identifiers.

Official guides: [Enable a repository](https://help.zenodo.org/docs/github/enable-repository/) · [Archive a GitHub release](https://help.zenodo.org/docs/github/archive-software/github-upload/).
